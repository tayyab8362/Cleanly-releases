# Cleanly for macOS

Clean your MacBook's keyboard, trackpad and screen without turning it off.
One click pauses your keyboard and trackpad and darkens the screen so every smudge shows.

**Buy a licence ($3, once):** https://tayyabrehman.gumroad.com/l/cleanly

This repository hosts the downloads and the automatic-update feed. The latest build is the
`Cleanly-<version>.dmg` file above; verify it against `SHA256SUMS.txt` if you like.
See [INSTALL.md](INSTALL.md) for first-launch steps and [PRIVACY.md](PRIVACY.md) for what
the app does (and doesn't do) with your data.

Bugs and ideas → [Issues](../../issues).
